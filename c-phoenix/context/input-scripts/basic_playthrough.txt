# Front 3 input script: coin-in, start 1-player, then basic movement/fire
# to exercise real gameplay for lockstep verification.
#
# Button holds are deliberately long (tens of frames), not single-frame
# pulses: clear_fore_and_background() (L0140) calls wait_vblank_coin()
# twice internally on top of the outer per-frame call, so frame_counter
# does not advance 1:1 with the outer dispatch loop that reads input in
# every code path. A short pulse can land entirely between the frames
# the game actually samples IN0. A real player's press also lasts many
# frames, so this matches authentic input timing anyway.

40 start1 press
100 start1 release
