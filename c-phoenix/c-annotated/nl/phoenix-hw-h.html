1. Invoerpoort $7000 (Inputs)

Knop-definities

De knoppen worden ingelezen via hw_read_inputs(). In overeenstemming met de originele Z80-hardware is een bit 0 wanneer een knop ingedrukt is en 1 wanneer deze niet is ingedrukt (standaard 0xFF = geen knoppen ingedrukt).

  • BTN_LEFT (0x40): Naar links bewegen.
  • BTN_RIGHT (0x20): Naar rechts bewegen.
  • BTN_FIRE (0x10): Vuren (spelerkogel).
  • BTN_SHIELD (0x80): Krachtveld/schild activeren.
  • BTN_START_1P (0x02): Start knop 1 speler.
  • BTN_START_2P (0x04): Start knop 2 spelers.
  • BTN_COIN (0x01): Munt-inworp sensor.

2. DIP-Switch Poort $7800

DIP-Switch Opties (hw_read_dsw)

  • Bits 0–1 (Levens): 11 = 3 levens, 01 = 4 levens, 10 = 5 levens, 00 = 6 levens.
  • Bits 2–3 (Bonusleven drempel): 11 = 3K/30K, 01 = 4K/40K, 10 = 5K/50K, 00 = 6K/60K.
  • Bit 4 (Muntsysteem): 1 = 1 munt/1 credit, 0 = 2 munten/1 credit.
  • Bit 5 (Kast-type): 1 = Cocktail, 0 = Upright.
  • Bit 7 (VBLANK vlag): 0 = in Vertical Blanking period, 1 = actief scherm.

3. Video- & Scroll-registers ($5000 / $5800)

hw_write_video_register & hw_write_scroll_register

  • hw_write_video_register(val) ($5000): Bit 0 selecteert RAM-bank (Bank 0 vs Bank 1), Bit 1 selecteert het actief kleurenpalet (Palette 0 vs Palette 1).
  • hw_write_scroll_register(val) ($5800): Stelt de achtergrond-verticale scrollpositie in.

4. Audio-latches ($6000 / $6800)

hw_write_sound_a & hw_write_sound_b

  • hw_write_sound_a(val) ($6000): Stuurt de geluidseffecten en frequentie-enveloppen aan.
  • hw_write_sound_b(val) ($6800): Stuurt de TMS3615 melodioselectie (bits 6-7) en ruis/sirene kanalen aan.
