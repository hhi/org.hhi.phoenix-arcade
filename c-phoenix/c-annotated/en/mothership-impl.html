1. Mothership Tile Matrix & Hit Scanning

l2351_mothership_animation

Description

The function l2351_mothership_animation (Z80 ROM: $2351–$23C7) drives the mothership animation and handles bullet impacts against its shield and core tiles, replacing hit tiles with destroyed tile graphics.

2. Shield Destruction & Core Explosion

mothership_core_hit_check

Description

The function mothership_core_hit_check (Z80 ROM: $2520–$254F) checks whether a player bullet penetrates the central core window, triggering mothership destruction and level victory.
