Description

2. Coin & Credit Management

prompt_for_start_game & decrement_coins

Description

The function prompt_for_start_game (Z80 ROM: $0288–$02EE) shows the start prompt once credits are present, and decrement_coins (Z80 ROM: $02CB–$02EF) deducts the credits when a game begins. Coin chute input itself is read by check_coin_event in scoring.c.

3. Intro Bird Animation

draw_intro_bird_animation_frame

Description

The function draw_intro_bird_animation_frame (Z80 ROM: $21DC–$2210) renders the 32-step intro bird animation gliding across the top title screen.
