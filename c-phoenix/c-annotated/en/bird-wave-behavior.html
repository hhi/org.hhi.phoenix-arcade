2. Egg Hatching & Growth Logic

update_bird_behavior

Description

The function update_bird_behavior (Z80 ROM: $35B0–$35DB) advances one bird through its behaviour script, including the egg-to-bird transformation, by dispatching on the script entry held in the bird record.

3. Dive Bombing & Swoop Attacks

l370a_grow_or_dive

Description

The function l370a_grow_or_dive rolls the random gate (M436F) that turns a growing bird into a diving one; the spawn decision itself lives in try_spawn_bird_dive_bomb.
