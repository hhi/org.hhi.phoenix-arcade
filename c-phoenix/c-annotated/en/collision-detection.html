Collision Detection (collision_detection.c) - C-Annotated Knowledge Graph Documentation

This document contains an annotated analysis of all functions in collision_detection.c. This module handles VRAM tile scanning, pixel mask collision detection, and explosion slot assignments for birds, eggs, and bullets.

1. VRAM Tile & Pixel Mask Scans

l38bc_large_hit

Description

The function l38bc_large_hit (Z80 ROM: $38BC–$38F1) executes bounding box and VRAM pixel mask collision checks for large bird sprites.

2. Bird & Egg Collision Slots

bird_explosion_slot

Description

The function bird_explosion_slot (Z80 ROM: $38F2–$3920) assigns a free explosion slot in RAM array 0x4378–$437C upon a fatal projectile hit.
