1. Mothership Descent Control

mothership_descent_logic

Description

The function mothership_descent_logic (Z80 ROM: $1E00–$1E40) steps through table phoenix_mothership_tile_page to lower the mothership vertical position per frame.

2. Erase & Bonus Scoring

erase_mothership

Description

The function erase_mothership (Z80 ROM: $246A–$2475) clears all 26x9 mothership tile graphics from background VRAM when defeated or reset.
