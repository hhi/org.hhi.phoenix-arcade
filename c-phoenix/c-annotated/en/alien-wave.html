1. Main Loop of Alien Wave

l2000_alien_wave_main_loop

Description

The function l2000_alien_wave_main_loop (Z80 ROM: $2000–$2060) executes the central game loop per VBlank frame for Waves 1, 3, and B.

Context & Invocation

Called from the main game state machine while playing an alien wave:

l2000_alien_wave_main_loop();

Step-by-Step Functionality

  1. Player & Collisions: Processes player controls via player_update and updates explosions via handle_animations_for_killed_aliens.
  2. Task Interleaving: Based on counter state.FrameInterleaveCounter & 3, executes one of four specific task bundles per frame:
    • case 0: Calls l2150 (Object RAM update & collision with player).
    • case 1: Calls l2160 (Enemy bombs & alien pattern scheduler).
    • case 2: Calls l2180 (Enemy bombs & dive-bomb attack triggers).
    • case 3: Calls l2190 (Collision check & breakout triggers).
  3. Background Scrolling: Calls l2130 to update starfield scrolling speed and registers.
