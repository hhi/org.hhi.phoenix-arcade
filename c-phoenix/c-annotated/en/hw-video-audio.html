This document contains an annotated analysis of all functions in hw_video_audio.c. This module implements the Z80 reset entry point (RESET), 60Hz VBlank interrupt handling, VRAM video buffer synchronization, and audio mixing calls.

1. VBlank Interrupt & Main Loop

phoenix_main_loop

Description

The function phoenix_main_loop (Z80 ROM: $0000–$004F) triggers 60 times per second to update VRAM video pages $4000–$433F and sound dispatchers.
